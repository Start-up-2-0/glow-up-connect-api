# Classificação de dados

| Nível | Exemplos | Controles |
|-------|----------|-----------|
| Público | Planos, vitrine loja | Rate limit, CORS |
| Interno | Logs operacionais | Acesso restrito |
| Confidencial | E-mail, telefone, agendamentos | Auth + RBAC |
| Restrito | Senha (hash), tokens, CPF pagamento | Criptografia, HttpOnly, mascaramento |
